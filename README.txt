INTERACTIVE PERSONAL PORTFOLIO
Built with HTML, CSS, JavaScript, Bootstrap 5 and Bootstrap Icons.
Frontend only — no server, database, or backend.

HOW TO RUN
1. Extract the ZIP file.
2. Open the interactive_portfolio folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

CUSTOMIZE BEFORE SUBMITTING
1. In index.html, replace "Your Name" and "YOUR NAME" with your name.
2. Replace the sample About Me text with your own introduction.
3. Update your school and course in the Education section.
4. Replace sample projects with your actual projects and links.
5. Update hello@example.com in index.html and script.js with your email address.
6. Replace GitHub and LinkedIn links with your profile URLs.
7. Replace the profile icon placeholder with your own photo if desired.

CONTACT FORM NOTE
The form validates the input and opens the visitor's default email application using a mailto link. It does not send or store messages on a server because this is a frontend-only project.

DEPENDENCIES
Bootstrap 5.3.3, Bootstrap Icons 1.11.3, and Google Fonts are loaded from CDNs, so an internet connection is needed for those resources.
